# AVIAN–OS · 现场遭遇 / 芦汀观测站

**[直接开始游玩](https://mcmcmcmmmc.github.io/avian-os/)** · 无需安装或登录，建议戴耳机。

v0.5 默认进入「现场遭遇」：20次参考真实资料编写的观鸟经历，每关都有地点、季节、天气、数量、生境、活动高度、行为、外形和真实参考录音。先观察环境、听见异常，再采取行动与修正猜测。

## 现场遭遇

1. **先保留猜测**：看到的是环境示意和最初笔记，不是大幅清晰鸟照。可选 1–3 个候选，记下当时的把握与已知线索。
2. **听、等、看**：听真实录音及其实时频谱，等待鸟移动，或举镜查看局部参考照片／未拍成照片的目击笔记。声音文字辅助可替代听音，但记录会区分二者。
3. **预测位置**：根据活动高度与换位方式，在树冠外缘、低灌丛、地面草叶间、开阔水边选择下一处观察位置。选中情境设定的位置会获得补充目击；没有等到不记为物种不存在。
4. **修改判断**：可以反复记下新的候选，保留每次猜测当时的信息。收集声音与一种目击后可结束；缺少补充目击时，即使名字猜中也不算证据充分。
5. **复盘整条线索**：查看本关设定的鸟种、近似种区分、自己的猜测变化，以及哪些来自资料、哪些属于虚构。

**柳莺专练：9种。** 黄眉、淡眉、黄腰、褐、巨嘴、极北、冕、冠纹、双斑绿柳莺。

**混合进阶：20种同一候选池。** 包括上述9种，以及小蝗莺、中华短翅蝗莺、矛斑蝗莺、北短翅蝗莺、鳞头树莺、树鹨、布氏鹨、理氏鹨、水鹨、红喉鹨、黄腹鹨。每种都有一场遭遇与真实参考录音，新加14场均没有完整照片，靠声音、目击笔记、行为和补充观察推进。

**有意无法定种的一关：** e11没有给出尾下覆羽等关键特征；保留中华／北短翅蝗莺两候选才符合证据。选中作者设定的单一物种仍不会算充分定种。

**名称和地理：** 北京市名录中的“田鹨”是 Anthus richardi，与理氏鹨合并，不算额外一种；“中华短翅莺”“北短翅莺”等别名有标注。新增红喉鹨、黄腹鹨用于非繁殖羽比较。稀少过境与常见繁殖分开说明；这是练习集合，不是完整名录。淡眉关依旧采用印度冬季背景，避免冒充北京声型。

所有精确地点、日期时刻、天气、数量、高度、目击顺序均为虚构。真实照片和声音也不是同一只鸟、同一现场：组合依据与原始出处都可查看。环境与活动动画是通用示意，补充目击是依资料编写的文字。尚未经过鸟类专家逐题审定，也不表示野外定种已被验证。

`?encounter=e11` 会直接进入混合进阶的证据不足关；`?encounter=e04` 可直接进入第四次遭遇。原来的辨认练习可从顶部切换，或用 `?mode=challenge` 打开；原自由观测用 `?mode=explore`。三种玩法的记录保留，互不覆盖。

## 旧版照片进阶练习

- 看不完整的照片，记录真正能看见的特征；没拍到的特征不能当作不存在。
- 最多勾选 3 个候选，或者暂不定种；留下把握与下一步想补的证据。
- 提交后查看照片档案标签、六种候选的图片和特征比较。档案标签来自原素材，**不是项目独立复核的定种结论**；进阶模式不计算正确率。
- 高把握会触发复核提醒，不直接判错。暂不定种也不被算作答对，提示继续缩小范围。
- 照片拍于不同地区；不伪造北京拍摄地点、季节、现场动作或叫声。九道照片题没有配套现场录音，按钮会明确说明缺失。
- 地区范围参考 Wild Beijing 的北京鸟种状态表，鉴别文字参考鸟类学组织与观鸟期刊。淡眉柳莺照片未核到亚种，不能用作北京当地种群的标准样本。完整依据和照片许可见 [ASSETS.md](ASSETS.md)。

基础练习、旧观测档案和录音保留，顶部可切换。深链接示例：`?case=w08` 进入松针间的头纹题，`?case=01` 进入朋友提供的开放案例。

## 基础练习

六个案例包括白鹡鸰、雄性北红尾鸲、树麻雀、普通翠鸟、白头鹎，以及一则北京秋季林下灰褐小鸟的开放案例。

- **看清外形**：查看真实参考照片与外形笔记。五张照片均随游戏本地提供，保留作者和许可。
- **等它动一动**：播放程序化动作示意，并将姿态、移动方式加入线索本。
- **听声音**：三段真实参考录音，可重听、停止，单次最多播放 12 秒；其余案例明确没有可靠录音。不会用合成音冒充真实识别证据。
- **做判断**：选择候选或「暂不定种」，选择把握程度，点选支持线索，附上可选笔记。
- **对照解释**：提交后显示关键特征、易混种比较与下一步观察建议。错误的高把握判断会提醒重新检查依据；谨慎保留不确定不会被当成高把握误判。
- **我的判断**：自动保存本浏览器中的作答历史，支持 JSON 导出。重复尝试会新增记录，不覆盖旧判断。

朋友提供的北京案例没有附带可核实的照片、录音或确认物种，所以作为开放题保留。图中是依据文字绘制的概括轮廓，不会替原始记录补造关键鉴别特征。候选并不穷尽全部可能，推荐先补充尾羽、腰部、翼斑和头脸特征。

情境为编写的练习。参考照片、录音与动作示意分别提供线索，不是同一地点、时间的现场实录；参考录音可能含其他背景声。所有外部素材的作者、许可和原始来源见 [素材说明](ASSETS.md)，界面中也可查看。

## 自由观测

导航中的「自由观测」保留 v0.1 湿地原型：六种持续活动的鸟、三处观察点、昼夜与天气、光学、热像、定向声音、FFT 声谱、候选推断、假信号、位置预测和观测档案。

该模式中的鸟鸣仍是原创合成音色，生态概率是未经野外校准的游戏模型；它与新版用于辨认的真实参考录音分开。两个模式的音频不会同时播放，原有档案保留独立存储键。

| 自由观测操作 | 快捷键 |
| --- | --- |
| 转动视角 | 拖动 / A、D / 左右方向键 |
| 光学、聆听、热像、闭眼 | 1、2、3、4 |
| 望远镜 | Z |
| 采集声纹 | 空格 |
| 目视确认 | P |

## 本地与离线运行

```sh
python3 serve.py
```

本机地址默认为 `http://127.0.0.1:18876/`。从 GitHub 克隆源码后也可生成单文件离线版：

```sh
python3 build.py
```

生成的 `芦汀观测站.html` 内嵌所有脚本、样式、参考照片和录音，约 23.7 MB；双击即可运行。`启动观测站.command` 也可打开已生成的离线文件。离线版中的外部来源链接仍需联网查看。

文件版与网站版、不同浏览器之间的本地记录不共享。记录保存在当前浏览器，重要内容请使用 JSON 导出。源码仓库不提交生成包、私人档案或测试导出数据。
