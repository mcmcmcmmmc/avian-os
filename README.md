# AVIAN–OS · 芦汀观测站

一个可离线运行的二维赛博观鸟游戏。你操作的是感知设备：从声音和模糊线索出发，采集证据、提出预测，最后用目视细节验证自己的判断。

**在线游玩：[打开芦汀观测站](https://mcmcmcmmmc.github.io/avian-os/)**。无需安装或登录，点击「开始观测」即可。

## 直接开始

- 双击 **`芦汀观测站.html`**，用现代浏览器打开。无需安装依赖。
- macOS 也可双击 **`启动观测站.command`**。
- 本机开发预览：`python3 serve.py`，默认地址 `http://127.0.0.1:18876/`。若端口被占用：`python3 serve.py --port 18877`。
- 点「开始观测」解锁浏览器音频，建议戴耳机。

从 GitHub 克隆源码后，先运行 `python3 build.py` 生成离线 HTML；也可直接运行 `python3 serve.py`。生成的离线包、测试截图和本地验收数据不提交到仓库。

浏览器直接打开文件时的本地存储规则可能不同。推荐一直使用同一个打开方式和浏览器；文件版与 HTTP 版档案不共享。重要档案请导出 JSON。

## 第一次怎么玩

1. 等右侧出现信号，点击它，视角会粗略转向声音。
2. 采集声纹，再读取栖息地。比较候选概率，注意“非鸟类 / 未知”。
3. 选择一个栖息地，锁定你对下一次目视位置的预测。
4. 热像可以帮助搜索，但松鼠也会发热，浓密树冠也会挡住热源。
5. 点击目视确认会先打开 6× 望远镜。拖动视野或按 A / D，水平对准目标，再次确认。被遮挡时安静等待；太远时换观察点。
6. 将外形细节、时间、位置、证据和预测结果保存到档案，可以写笔记并导出。

地图只显示地形、观察点和声音大致方位，不公开所有鸟的位置。换观察点会惊扰附近鸟类。预测会保留，重新捕获同一信号后仍可验证。

| 操作 | 快捷键 |
| --- | --- |
| 转动视角 | 拖动 / A、D / 左右方向键 |
| 光学、定向聆听、热像、闭眼 | 1、2、3、4 |
| 望远镜 | Z |
| 采集声纹 | 空格 |
| 目视确认 | P |

移动端支持拖动，视野下方还有声纹、环境、热像和目视快捷按钮。

## 本版内容

- 六种鸟：普通翠鸟、白鹭、夜鹭、黑水鸡、白头鹎、鹊鸲。
- 一个简化湿地、四类栖息地、三个观察点。
- 持续存在的个体；觅食、飞行、停栖、休息、躲藏状态，不能靠反复扫描生成新鸟。
- 时间与天气影响活动、噪声、温度和可视距离。行为选择还考虑栖息地权重、简化食物资源、繁殖强度、其他个体密度与玩家干扰。
- 左右声像；定向模式衰减偏离指向的声音；合成鸟声与环境底噪。
- 实时 FFT 声谱。谱图反映正在播放的合成音频；声纹采集输出模拟的带噪特征，不是机器学习音频识别器。
- 只依赖观测特征的概率模型，同类证据去重，不会因连续点击把置信度刷高。
- 风吹叶片、塑料袋、松鼠、自行车刹车等假信号。视觉证据可以推翻之前的第一候选。
- 场景暂停、昼夜时间轴、四种天气、静候五分钟、识别手册、个人记录与 JSON 导出。

## 模型和素材边界

所有风景、鸟形与音色均由本项目代码生成，没有外部字体、图片、音频或第三方网络依赖。鸟类形象为简化示意，**合成音色不能用来学习真实鸟鸣**。

生态规则、栖息地资源和概率似然是手工设置的游戏参数，未经野外数据校准；概率不是现实物种出现率。这里没有调用云端 AI，也没有实现正式 POMDP 求解。左右声像不是 AirPods 头部追踪。食物与种间影响是权重层面的简化，不是完整捕食网络。

本版完成最小可玩循环。三维世界、多日隐藏鸟剧情、真实音源识别、生态消失调查及正式认知升级树不在本版内；“六种鸟的完整目视档案”作为当前长期目标。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `engine.js` | 物种与环境参数、个体行为、观测条件、独立概率推断 |
| `audio.js` | Web Audio 合成、声像、指向衰减、频谱分析器 |
| `render.js` | 程序化湿地、鸟形、热像、地图和声谱绘制 |
| `app.js` | 输入、采证、预测、记录、本地存储和界面状态 |
| `index.html` / `style.css` | 界面结构与响应式样式 |
| `build.py` | 将源码打包为单个离线 HTML |
| `tests/` | 开发期逻辑测试和浏览器验收脚本，不嵌入离线 HTML |
| `evidence/` | 浏览器截图、自动验收结果和测试导出记录 |

```sh
node --test tests/engine.test.cjs
python3 build.py
python3 serve.py --no-open
```

浏览器验收需要开发环境提供 Playwright：

```sh
PLAYWRIGHT_PATH=/path/to/node_modules/playwright node tests/browser.cjs
```

浏览器测试使用临时浏览器上下文，不会把测试档案写入你的正常浏览器。`evidence/export-test.json` 是自动化产生的测试数据，不是真实野外记录。

详细验证范围见 `VALIDATION.md`。
