# AVIAN–OS · 现场猜鸟 / 芦汀观测站

**[直接开始游玩](https://mcmcmcmmmc.github.io/avian-os/)** · 无需安装或登录，建议戴耳机。

v0.2 把「根据现场线索自己辨认鸟种」设为默认玩法：看画面、听声音，结合地点、季节、时间、数量、生境、体色和姿态，选择鸟种、标记依据和把握程度，提交后再查看解释。答题前不显示 AI 概率排名。

## 现场猜鸟

六个案例包括白鹡鸰、雄性北红尾鸲、树麻雀、普通翠鸟、白头鹎，以及一则北京秋季林下灰褐小鸟的开放案例。

- **看清外形**：查看真实参考照片与外形笔记。五张照片均随游戏本地提供，保留作者和许可。
- **等它动一动**：播放程序化动作示意，并将姿态、移动方式加入线索本。
- **听声音**：三段真实参考录音，可重听、停止，单次最多播放 12 秒；其余案例明确没有可靠录音。不会用合成音冒充真实识别证据。
- **做判断**：选择候选或「暂不定种」，选择把握程度，点选支持线索，附上可选笔记。
- **对照解释**：提交后显示关键特征、易混种比较与下一步观察建议。错误的高把握判断会提醒重新检查依据；谨慎保留不确定不会被当成高把握误判。
- **我的判断**：自动保存本浏览器中的作答历史，支持 JSON 导出。重复尝试会新增记录，不覆盖旧判断。

朋友提供的北京案例没有附带可核实的照片、录音或确认物种，所以作为开放题保留。图中是依据文字绘制的概括轮廓，不会替原始记录补造关键鉴别特征。候选并不穷尽全部可能，推荐先补充尾羽、腰部、翼斑和头脸特征。

情境为编写的练习。参考照片、录音与动作示意分别提供线索，不是同一地点、时间的现场实录；参考录音可能含其他背景声。所有外部素材的作者、许可和原始来源见 [素材说明](ASSETS.md)，界面中也可查看。

## 自由观测

导航中的「自由观测」保留 v0.1 湿地原型：六种持续活动的鸟、三处观察点、昼夜与天气、光学、热像、定向声音、FFT 声谱、候选推断、假信号、位置预测和观测档案。

该模式中的鸟鸣仍是原创合成音色，生态概率是未经野外校准的游戏模型；它与新版用于辨认的真实参考录音分开。两个模式的音频不会同时播放，原有档案保留独立存储键。

| 自由观测操作 | 快捷键 |
| --- | --- |
| 转动视角 | 拖动 / A、D / 左右方向键 |
| 光学、聆听、热像、闭眼 | 1、2、3、4 |
| 望远镜 | Z |
| 采集声纹 | 空格 |
| 目视确认 | P |

## 本地与离线运行

```sh
python3 serve.py
```

本机地址默认为 `http://127.0.0.1:18876/`。从 GitHub 克隆源码后也可生成单文件离线版：

```sh
python3 build.py
```

生成的 `芦汀观测站.html` 内嵌所有脚本、样式、参考照片和录音，约 5 MB；双击即可运行。`启动观测站.command` 也可打开已生成的离线文件。离线版中的外部来源链接仍需联网查看。

文件版与网站版、不同浏览器之间的本地记录不共享。记录保存在当前浏览器，重要内容请使用 JSON 导出。源码仓库不提交生成包、私人档案或测试导出数据。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `challenge-data.js` | 六个案例、线索、答案与开放题规则 |
| `challenge.js` | 查看线索、录音播放、作答、解释、历史与导出 |
| `challenge-art.js` | 现场与鸟类动作的程序化示意 |
| `challenge.css` | 猜鸟模式的桌面与手机界面 |
| `assets/reference/` / `media-credits.js` | 本地参考素材与署名许可元数据 |
| `engine.js` / `audio.js` / `render.js` / `app.js` | 原自由观测世界、合成音、绘制与交互 |
| `build.py` | 单文件离线打包，包括新素材 |
| `tests/` | 逻辑、猜鸟浏览器验收、旧模式回归测试 |

```sh
npm test
PLAYWRIGHT_PATH=/path/to/node_modules/playwright node tests/challenge-browser.cjs
PLAYWRIGHT_PATH=/path/to/node_modules/playwright node tests/browser.cjs
```

第二、三条命令需要本地预览服务和 Playwright。可设置 `TEST_WEBKIT=1` 使用 WebKit，设置 `BASE_URL` 检查已发布页面。测试使用独立的临时浏览器上下文，不会把测试答案写进你的正常浏览器。

验证范围与局限见 [VALIDATION.md](VALIDATION.md)。本项目没有真实鸟鸣识别算法，也不提供真实野外定种保证。
